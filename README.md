# Car Rental Calculator

An interactive car rental booking calculator built with JavaScript that estimates rental costs based on duration, selected features, and customer age.

**GitHub:** [github.com/Kodelack47/CarRental](https://github.com/Kodelack47/CarRental)

## Features

- Date picker for rental start date
- Number of days selection
- Optional add-ons: Electronic toll tag, GPS, roadside assistance
- Age-based surcharge detection
- Real-time cost breakdown
- Final total calculation

## How to Use

1. Clone this repository
2. Open `index.html` in your browser
3. Select rental start date and number of days
4. Choose optional add-ons (each adds daily charges)
5. Indicate if driver is under 25
6. Click "Estimate Total Cost" to see breakdown
